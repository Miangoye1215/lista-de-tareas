# Lista de Tareas (To-Do List)

Aplicación web para gestionar tareas diarias: agregar, marcar como completadas y eliminar. Las tareas se separan visualmente en dos secciones (pendientes y completadas) según su estado.

## Tecnologías

- HTML5
- JavaScript (Vanilla, sin frameworks)

## Funcionalidades

- Agregar nuevas tareas mediante un input y botón
- Marcar tareas como completadas con checkbox (se tachan visualmente)
- Eliminar tareas individualmente
- Separación automática entre tareas pendientes y completadas
- El estado de cada tarea se guarda en memoria como parte de un array de objetos

## Cómo ejecutarlo

1. Clona este repositorio o descarga los archivos
2. Abre `index.html` en tu navegador
